# Assignment 01 - Deep Learning

## Title
Install and configure TensorFlow/Keras in Google Colab. Perform data preprocessing, normalization, train-test splitting, and data visualization on the MNIST dataset.

## Objective
- Load the MNIST handwritten digits dataset.
- Perform data preprocessing and normalization.
- Visualize sample images.
- Build a neural network using TensorFlow/Keras.
- Train and evaluate the model.
- Predict digit labels.
- Save the trained model.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Google Colab

## Dataset
MNIST Handwritten Digits Dataset (loaded directly using `tensorflow.keras.datasets.mnist`).

## Files
- `Assignment01DL.ipynb` – Google Colab notebook

## Output
- Dataset visualization
- Training and validation accuracy
- Loss graphs
- Test accuracy
- Predicted vs actual labels
